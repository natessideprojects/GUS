01 / WINDOWS & YOUR OWN DRIVE

A portable folder, not a single EXE.

Before you begin

Use a 64-bit Windows 10/11 PC. Allow at least 12 GB free on your PC while joining and extracting North Georgia; its extracted Windows app is about 4 GB. You can then copy the extracted folder to your portable drive. DIY is about 1.6 GB extracted; allow at least 4 GB free for its ZIP and extracted copy. A 16 GB or larger USB drive or external SSD leaves useful room for your files. Actual download sizes appear on the download page.

  1. Download the correct complete ZIP

    Open Downloads. For North Georgia Windows, save both .zip.001 and .zip.002 parts in the same folder. For DIY, save the single Windows ZIP. Wait for every download to finish. The North Georgia APK is a separate download.

  2. Check the download

    Compare the ZIP SHA-256 with the checksum published beside the release. In PowerShell, use Get-FileHash -Algorithm SHA256 "C:\path\to\download.zip". Check the release page and expected filename before running an unsigned demo.

  3. Join the North Georgia parts (DIY skips this step)

    In File Explorer, open the folder containing both parts. Type cmd in its address bar and press Enter to open Command Prompt there. Run copy /b "GUS-North-Georgia-Windows-Demo.zip.001"+"GUS-North-Georgia-Windows-Demo.zip.002" "GUS-North-Georgia-Windows-Demo.zip". This creates the complete ZIP and leaves both parts intact. Wait for it to finish, then check the joined ZIP against its separate checksum. Do not try to extract a part on its own.

  4. Extract everything

    Right-click the ZIP and choose Extract All. Choose a new local folder outside OneDrive. Do not open the app from inside the ZIP. Wait until extraction finishes.

  5. Copy the whole folder to your drive

    If you extracted to your PC first, copy the complete extracted app folder to the USB drive or external SSD. Keep the top-level EXE, System and OWNER_FILES together. Never move only the EXE.

  6. Open the top-level launcher

    Run GUS North Georgia.exe or G.U.S. DIY.exe from the extracted app folder. Read the app terms and disclaimer. Windows may identify the unsigned demo as unrecognized; only proceed if you trust the source and have verified the file. Do not disable Windows protection globally.

  7. Check a small task before travelling

    Let initialization finish. Open a bundled source, try a search and check its citation. For North Georgia, open the offline map. Close the app before disconnecting your drive, and use Windows Safely Remove Hardware.

Slow flash drives can take many minutes to copy thousands of files. A faster USB 3 drive or external SSD usually feels better. Mac and Linux builds are not provided.

02 / NORTH GEORGIA ANDROID

Install once. Carry it on your phone.

Check compatibility

Android 8.0+ on a 64-bit ARM device (arm64-v8a), at least 5 GB free internal storage, and 6 GB RAM recommended; 8 GB or more is more comfortable. The APK is about 1.6 GB. This is a debug-signed demo, not a Play Store production release. No iPhone or DIY Android app is supplied.

  1. Get the APK onto the phone

    Download the North Georgia Android v53 APK directly on your phone, or copy it from your computer or USB drive into Downloads. A USB adapter may be needed for a flash drive. Use a stable connection for this large file.

  2. Open it in Files or My Files

    Tap the completed .apk download in Android’s file manager. If Android asks, permit Install unknown apps only for the file manager or browser you are deliberately using for this download. Device wording varies.

  3. Let Android finish installing

    Confirm Install and leave the installer alone until it finishes. If installing from USB, keep the drive connected. Do not remove the drive or interrupt a large installation.

  4. Finish first-launch preparation

    Open GUS North Georgia. Keep it open while it copies the offline guide, model, references and regional map into private phone storage. Allow several minutes; slow storage may take longer. This step is local and does not need internet.

  5. Check status and location preferences

    Read the terms and disclaimer. Open More → Status and confirm the offline pack is ready. Grant location access only if you want phone-location features. Try Map and open a reference document before relying on the setup away from service.

  6. Add your own reference files

    Use More → My Files → Add Files or GPX/KML. Select supported files in Android’s picker. GUS copies and scans them in private storage. Keep the original files elsewhere, and use Export All My Files (.zip) for backups.

After installation, Android runs from internal storage; the USB drive is no longer needed. You can turn off the installer’s Install unknown apps permission again after setup. If installation fails, check completed download size, the checksum, free storage and ARM64 compatibility before retrying.

03 / BUILD YOUR DIY LIBRARY

Your documents go in OWNER_FILES.

On Windows, open My Files → Open OWNER_FILES Folder. Add supported PDF, Markdown, TXT, HTML/HTM, DOCX, GPX, KML or KMZ reference files, then choose Scan My Files. Start with copies of a few files. Scanned PDFs need extra time for local OCR on the first scan; later scans can reuse the cache.

Ask a focused question, inspect the citation and use View Cited Page for PDF evidence. OCR may misread numbers, units, symbols or tables. A successful scan does not guarantee an accurate answer. Keep maps, routes and document statements distinct from current real-world conditions.

04 / KEEP YOUR WORK

Back up before every update.

  • Windows: close GUS and back up the whole old app folder and your OWNER_FILES. For a test update, extract into a separate new folder and import copies of your files. Do not overwrite personal folders with the clean demo’s empty folders.
  • Android: export My Files and retain originals before updating. Version 53 uses the existing preview signing identity. An APK with the same app ID and certificate can normally update in place; do not uninstall just to work around a signing error.
  • Uninstalling or clearing Android storage deletes private app copies. Export documents, notes, photos and saved routes first.
  • There is no automatic Windows/Android sync. Use the apps’ My Files export/import ZIP tools and transfer the ZIP yourself. A backup is not a guarantee that every app preference migrates.
