01 / NORTH GEORGIA ADVENTURE DRIVE

Know your corner.
Carry it with you.

A regional reference library for North Georgia, with local search, source passages, outdoor guidance, maps and your own trip documents. Available as complete Windows and Android testing demos.

WHAT YOU CAN USE IT FOR

A field library for
the planning part.

  • Look into a trip. Browse hiking, camping, paddling, fishing, cycling and motorcycle-related material and stored place records.
  • Bring your references. Keep trip notes, readable PDFs, saved pages and GPX/KML files together.
  • Look up practical information. Search the guide, dictionary, figures, tables, calculators and stored reference documents.
  • Trace an answer. Follow numbered citations to inspect the stored source and its limits.
  • Plan with the map. View regional geometry, open an individual track and save supported route plans.

PICK YOUR PLATFORM

The same project. Different map behavior.

WINDOWS 10 / 11

A portable planning desk.

Run the complete extracted folder from a PC, USB drive or external SSD. Windows maps support offline reference and supported static car-route planning. There is no live GPS, traffic feed or live closure service.

Install on your drive →
ANDROID 8+ / ARM64

A reference on your phone.

The APK bundles the Organic Maps engine and North Georgia map data. With permission, it can use phone location and calculate supported offline routes inside its map coverage. It does not need the USB connected after installation.

Install the APK →
A mapped place is not a promise of access.

Check permissions, entrances, closures, weather and source dates independently. GUS is not an emergency service or a substitute for a current map, local advice or professional guidance.
